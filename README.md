# Logistics Requirements Engine (LRE)

> Автономный интеллектуальный микросервис формирования содержательных требований к перевозке грузов на базе гибридной нейро-символьной архитектуры: **Rule Engine + Семантический NLP-парсинг + Интерпретируемая концептуальная нейросеть (Concept-Bottleneck Network)** с независимой панелью визуализации **LRE-Visualizer**.

---

## Архитектура решения

```
┌─────────────────┐       POST /v1/requirements/infer      ┌──────────────────────┐
│      КИС2       │ ───────────────────────────────────────►│       LRE-Core       │
│ (Данные заявки) │ ◄───────────────────────────────────────│  (FastAPI Backend)   │
└─────────────────┘             Требования + Rationale      └──────────┬───────────┘
                                                                       │
                                      Сохранение трассировки активаций │
                                                                       ▼
                                                            ┌──────────────────────┐
                                                            │    LRE-Visualizer    │
                                                            │ (Canvas Мониторинг)  │
                                                            │ http://localhost:8080│
                                                            └──────────────────────┘
```

### Ключевые компоненты:
1. **Rule Engine (Нормативный блок):** Гарантирует 100% соблюдение законодательства и физических нормативов (ПДД по габаритам автопоездов, весовые ограничения, правила перевозки опасных грузов ДОПОГ/ADR, ветеринарный и карантинный контроль).
2. **Семантический NLP-парсер:** Локальный анализатор неструктурированных примечаний («не кантовать», «боится осадков», «кран-балка», «без перегрузки»).
3. **Concept-Bottleneck Neural Net (NumPy):** 3-слойная концептуальная нейросеть с полной объяснимостью. Каждый скрытый нейрон $Z$ олицетворяет физико-логистический фактор (негабарит, риск перегруза по осям, смещение центра тяжести, риск кантования). Сеть инициализирована экспертной матрицей связей (работает с холодного старта при 0 датасете).
4. **Parameter Extractor:** Автоматически вычисляет числовые и технические параметры (грузоподъемность крана с запасом 25%, тип трала, допустимую высоту площадки, параметры крепежных цепей).
5. **LRE-Visualizer (Standalone Web Dashboard):** Независимая веб-панель мониторинга, отображающая «живой мозг» системы: граф нейронов, свечение активаций, бегущие световые импульсы по связям, интерактивный инспектор влияния и симулятор What-If.

## Быстрый запуск

### Вариант 1: Локальный запуск (Windows PowerShell)

Все зависимости уже установлены в локальное виртуальное окружение `.venv` внутри папки проекта.

Запустите скрипт:
```powershell
.\run_dev.ps1
```

Или вручную:
```powershell
# Терминал 1: Запуск API
.\.venv\Scripts\python -m uvicorn lre_core.app:app --host 0.0.0.0 --port 8000 --reload

# Терминал 2: Запуск Visualizer
cd lre_visualizer
..\.venv\Scripts\python -m http.server 8080
```

- **Swagger документация API:** [http://localhost:8000/docs](http://localhost:8000/docs)
- **Дашборд визуализатора нейросети:** [http://localhost:8080](http://localhost:8080)

---

### Вариант 2: Запуск через Docker Compose

```bash
docker-compose up --build -d
```

- `lre-core`: порт `8000`
- `lre-visualizer`: порт `8080`
